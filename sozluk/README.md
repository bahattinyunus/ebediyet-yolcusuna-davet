# 📖 Kavramsal Sözlük ve Istılah Rehberi (Kavramsal API Referansı)

> *"Kelimelere takılma, manaya odaklan; fakat kilit kavramların haritasını elinde tut ki hazinenin kapıları hızla açılsın."*

Risale-i Nur Külliyatı'nda geçen Kur'anî ve kelâmî ıstılahlar, rastgele seçilmiş eski kelimeler değil; tek bir kelimeyle koca bir hakikat dünyasını taşıyan **yüksek yoğunluklu kavram paketleridir (`high-density semantic primitives`).** Bu sözlük, metinleri okurken zihninin takılmaması için temel kavramları **klasik tanımı**, **modern bilişsel/sistem karşılığı** ve **geçtiği temel Risalelerle** birlikte açıklar.
